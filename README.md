# CryptoLab

A research and experimentation lab for cryptocurrency markets, paper trading, algorithmic trading, AI research, and proof-of-work mining analysis.

## Current stage

Stage 1 — Market data foundation.

- No real-money trading
- No exchange API keys committed to the repository
- Research and paper trading first

## Roadmap

1. Market data collection
2. Technical indicators
3. Paper trading engine
4. Backtesting
5. Risk management
6. Machine learning / AI research
7. Exchange API integration
8. Mining and PoW profitability analysis
